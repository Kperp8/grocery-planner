# GroceryPlanner

Aplikacja internetowa służąca ograniczaniu marnowania produktów spożywczych poprzez inteligentne rozplanowywanie zakupów.

## Funkcje

| Obszar | Co robi |
| --- | --- |
| Planowanie przepisów | Generowanie listy przepisów na podaną liczbę dni tak, żeby ich składniki pokrywały się w jak największym stopniu, w celu minimalizacji odpadów |
| Planowanie zakupów | Planowanie wizyt w sklepie dla wygenerowanego planu posiłków wraz z uwzględnieniem dostępności w sklepie, dat ważności oraz obecnego stanu |
| Przechowywanie/edytowanie przepisów | Możliwość dodawania i edytowania przepisów |

## Szybki start

```bash
git clone https://github.com/Kperp8/grocery-planner.git
cd GroceryPlanner
docker compose up --build -d
docker compose exec php composer dump-autoload
```

Aplikacja: http://localhost:8080
